# Monte Carlo Stock Price Simulator

A Python simulation of stock price movements using Geometric Brownian Motion (GBM).

Built as part of a quantitative finance portfolio project.

## What this project does
- Simulates thousands of possible future stock price paths
- Uses real statistical concepts: drift, volatility, and log-normal returns
- Visualises outcomes with confidence intervals

## Tools used
- Python 3
- Jupyter Notebook
- numpy, matplotlib, scipy
